\section{Contexto y Base Te\'orica}
\subsection{Resumen ejecutivo}
Este documento organiza la gesti\'on del proyecto con Scrum y deja una base corta, formal y modular para Overleaf. El foco es el MVP de una plataforma web de mascotas urbanas y rurales con fotos reales, modelos 3D locales y edici\'on b\'asica.

\subsection{Visi\'on del producto}
La visi\'on es construir una plataforma donde una persona usuaria pueda registrarse, iniciar sesi\'on, gestionar mascotas urbanas y rurales, subir fotos y personalizar modelos 3D locales sin modificar los archivos originales.

\subsection{Alcance del MVP}
\begin{itemize}[leftmargin=*]
    \item Registro e inicio de sesi\'on.
    \item Alta y consulta de mascotas por usuario con contexto urbano/rural.
    \item Carga de fotos reales por mascota.
    \item Visualizaci\'on de modelos 3D desde \texttt{backend/Modelos}.
    \item Edici\'on b\'asica de transformaciones 3D.
    \item Persistencia y trazabilidad funcional.
\end{itemize}

\subsection{Fuera de alcance inmediato}
\begin{itemize}[leftmargin=*]
    \item Personalizaci\'on avanzada o colaborativa de modelos 3D.
    \item Panel administrativo avanzado.
    \item Integraci\'on externa con cat\'alogos de terceros.
\end{itemize}

\subsection{Fundamento Scrum}
Scrum es un marco ligero que ayuda a generar valor mediante soluciones adaptativas para problemas complejos \cite{schwaber2020}. Se apoya en transparencia, inspecci\'on y adaptaci\'on.

\subsection{Valores Scrum}
Los cinco valores son compromiso, foco, apertura, respeto y coraje \cite{schwaber2020}. En este proyecto se usan como gu\'ia para la colaboraci\'on y la entrega incremental.

\subsection{Product Goal}
Entregar una plataforma funcional donde una persona usuaria pueda crear su cuenta, iniciar sesi\'on, registrar mascotas urbanas/rurales, subir fotos y visualizar o editar un modelo 3D local asociado.
