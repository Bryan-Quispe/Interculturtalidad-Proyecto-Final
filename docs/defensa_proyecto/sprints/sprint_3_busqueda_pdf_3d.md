# Sprint 3: busqueda, fotos, modelos 3D y PDF

## Objetivo

Mejorar la ficha de mascota perdida incorporando fotos, ubicacion aproximada, modelos 3D y exportacion PDF.

## Alcance

- Cargar fotos de mascotas.
- Mostrar fotos sin recorte fuerte.
- Registrar zona aproximada.
- Integrar modelos 3D por categoria.
- Filtrar modelos segun especie.
- Exportar PDF de busqueda.

## Historias de usuario

| Historia | Descripcion | Prioridad |
| --- | --- | --- |
| HU-07 | Como usuario quiero subir fotos reales de mi mascota. | Alta |
| HU-08 | Como usuario quiero indicar donde fue vista por ultima vez. | Alta |
| HU-09 | Como usuario quiero seleccionar un modelo 3D compatible. | Alta |
| HU-10 | Como usuario quiero generar un cartel PDF. | Alta |

## Entregables

- Soporte de fotografias.
- Selector de categoria.
- Catalogo de modelos 3D.
- Visualizador 3D.
- Ficha exportable en PDF.
- Regla de privacidad para ubicacion aproximada.

## Validacion

- El PDF contiene datos principales.
- Las fotos se muestran completas.
- La captura 3D se agrega al PDF.
- No se muestra ubicacion exacta como dato publico principal.
- Los modelos se filtran por categoria.

## Resultado

Sprint completado. El sistema ya puede funcionar como herramienta de apoyo para busqueda y difusion de mascotas perdidas.
