# Documentacion de defensa del proyecto Mascotas 3D

Esta carpeta reune la documentacion necesaria para defender el proceso de desarrollo del proyecto **Mascotas 3D**, una aplicacion web orientada a registrar mascotas perdidas, asociarlas con su dueno, cargar fotografias, ubicar una zona aproximada de avistamiento y usar modelos 3D como apoyo visual para generar una ficha o cartel exportable.

## Estructura de la carpeta

| Documento | Proposito |
| --- | --- |
| `00_resumen_ejecutivo.md` | Explica el problema, la solucion y el alcance general. |
| `01_sprints.md` | Presenta el desarrollo por sprints, con objetivos, entregables y estado. |
| `02_requisitos.md` | Resume requisitos funcionales y no funcionales. |
| `03_arquitectura.md` | Describe frontend, backend, base de datos, almacenamiento y flujo de datos. |
| `04_implementacion.md` | Explica que se implemento y que componentes tecnicos se usaron. |
| `05_validacion.md` | Describe como se valido con usuarios, reglas de negocio y criterios de aceptacion. |
| `06_verificacion.md` | Documenta pruebas tecnicas, compilacion y revision de funcionamiento. |
| `07_mantenimiento.md` | Define mantenimiento correctivo, adaptativo, preventivo y perfectivo. |
| `08_manual_uso.md` | Guia breve de uso para usuario, administrador y exposicion. |
| `09_guia_exposicion.md` | Guion rapido para presentar el proyecto y defender decisiones. |
| `sprints/` | Documentos individuales de Sprint 1, 2, 3 y 4. |
| `evidencias/` | Carpeta sugerida para capturas, PDFs exportados y pruebas. |

## Como usar esta documentacion en la defensa

1. Iniciar con `00_resumen_ejecutivo.md` para explicar el contexto del proyecto.
2. Usar `01_sprints.md` para demostrar que el desarrollo siguio un proceso incremental.
3. Mostrar `03_arquitectura.md` y `04_implementacion.md` para sustentar la parte tecnica.
4. Usar `05_validacion.md` y `06_verificacion.md` para explicar como se comprobo la calidad.
5. Cerrar con `07_mantenimiento.md` y `09_guia_exposicion.md` para mostrar continuidad del proyecto.

## Estado general

El sistema ya cuenta con autenticacion, gestion de mascotas por usuario, vista administrativa, carga de imagenes, modelos 3D categorizados por especie, edicion visual del modelo, ubicacion aproximada y exportacion de ficha PDF. El Sprint 4 se mantiene como evolucion principal para mejorar la edicion tipo paint sobre modelos 3D con textura original.
