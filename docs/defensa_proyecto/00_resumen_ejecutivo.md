# Resumen ejecutivo

## Nombre del proyecto

**Mascotas 3D: sistema web para busqueda y gestion de mascotas perdidas con apoyo visual tridimensional.**

## Problema identificado

Cuando una mascota se pierde, la informacion suele difundirse por mensajes, redes sociales o carteles poco estructurados. Esto provoca datos incompletos, fotografias aisladas, ubicaciones imprecisas y dificultad para reconocer al animal. Ademas, publicar una direccion exacta puede representar un riesgo de privacidad para el dueno.

## Solucion propuesta

El proyecto propone una aplicacion web donde cada usuario puede registrar sus mascotas, cargar fotografias reales, seleccionar una categoria de especie, asociar un modelo 3D compatible y registrar una zona aproximada donde fue vista por ultima vez. El sistema genera una ficha exportable en PDF con la informacion necesaria para apoyar la busqueda sin exponer datos sensibles.

## Objetivo general

Desarrollar una aplicacion web funcional que permita registrar, visualizar, buscar y documentar mascotas perdidas mediante informacion estructurada, fotografias, ubicacion aproximada y modelos 3D como guia visual.

## Objetivos especificos

- Permitir el registro e inicio de sesion de usuarios.
- Asociar mascotas a su propietario.
- Permitir que el administrador visualice y filtre mascotas registradas.
- Registrar categoria de mascota: perro, gato o conejo.
- Filtrar modelos 3D segun la categoria seleccionada.
- Cargar fotografias de la mascota y conservarlas como evidencia visual.
- Registrar zona o barrio aproximado de Quito/Ecuador mediante seleccion asistida.
- Evitar publicar ubicaciones exactas por seguridad.
- Exportar un cartel o ficha PDF con informacion, fotos y captura del modelo 3D.
- Permitir la edicion visual del modelo 3D para personalizar rasgos importantes.

## Alcance actual

El sistema cubre el flujo principal: registro de usuario, autenticacion, registro de mascota, seleccion de categoria, asociacion de modelo 3D, carga de imagenes, detalle de mascota, administracion, visualizacion publica y exportacion de ficha PDF. La edicion avanzada tipo paint sobre textura original se plantea como evolucion del Sprint 4.

## Usuarios principales

| Usuario | Necesidad |
| --- | --- |
| Dueno de mascota | Registrar una mascota perdida, subir fotos y generar un cartel. |
| Visitante | Ver mascotas reportadas en una zona aproximada. |
| Administrador | Revisar mascotas de todos los usuarios y controlar modelos 3D. |

## Valor del proyecto

El valor principal del sistema es combinar informacion real de la mascota con una representacion 3D que ayuda a identificar rasgos visuales. A diferencia de un cartel comun, la ficha generada se construye con datos organizados y puede incluir fotos, caracteristicas, zona aproximada y contacto.
