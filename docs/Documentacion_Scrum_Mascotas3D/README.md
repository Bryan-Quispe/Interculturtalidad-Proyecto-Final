# Documentación Scrum profesional - Mascotas 3D

**Proyecto:** Aplicación web para búsqueda de mascotas perdidas con apoyo visual 3D  
**Responsable:** Bryan Quispe  
**Marco de trabajo:** Scrum, adaptado a un proyecto académico  
**Estado del incremento:** Cuatro sprints implementados y verificables en el repositorio  
**Última actualización:** 18 de julio de 2026

## Propósito

Esta carpeta reúne la documentación necesaria para explicar, demostrar y defender el proceso de desarrollo de Mascotas 3D mediante Scrum. Los documentos describen decisiones y funcionalidades comprobables en el código. Las actas que requieren firmas, fechas de reunión o participantes reales se incluyen como plantillas y no como evidencia inventada.

## Convención de estado

- **Completado:** existe implementación y puede demostrarse.
- **Parcial:** existe una base funcional, pero queda una mejora conocida.
- **Planificado:** todavía no forma parte del incremento verificable.
- **Plantilla:** formato preparado para registrar información real posteriormente.
