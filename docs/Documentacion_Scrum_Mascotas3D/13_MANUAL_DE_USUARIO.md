# Manual de usuario

## 1. Crear una cuenta

1. Abrir la opción de registro.
2. Escribir nombre, correo y contraseña.
3. Confirmar el registro.
4. Iniciar sesión con las credenciales creadas.

## 2. Registrar una mascota

1. En el dashboard, seleccionar `Nueva mascota`.
2. Escribir nombre y elegir perro, gato o conejo.
3. Añadir raza, descripción y características visibles.
4. Cargar fotografías claras desde varios ángulos.
5. Seleccionar en Google Maps la zona aproximada del último avistamiento.
6. Registrar fecha, referencia y teléfono.
7. Guardar.

## 3. Asociar un modelo 3D

1. Abrir la mascota.
2. Seleccionar `Asignar modelo 3D`.
3. Revisar los modelos compatibles con su categoría.
4. Elegir la referencia más parecida.

## 4. Personalizar el modelo

1. Abrir `Editar modelo`.
2. Usar `Rotar` para buscar el lado que se desea modificar.
3. Usar `Zoom` para acercar o alejar.
4. Seleccionar `Pintar`.
5. Elegir lápiz, pincel o brocha y un color.
6. Arrastrar sobre la superficie.
7. Usar `Deshacer` o `Limpiar` si es necesario.
8. Elegir si el resultado será público o privado.
9. Guardar.

## 5. Preparar el cartel

1. Abrir `Ver ficha y exportar`.
2. Acomodar el modelo si se desea incluir esa vista.
3. Seleccionar `Preparar cartel PDF`.
4. Revisar y editar el texto del cartel.
5. Marcar las fotografías que se incluirán.
6. Elegir la imagen principal y ordenar las demás.
7. Escoger cuadrícula o fotografías grandes.
8. Decidir si se incluyen ficha detallada y página 3D.
9. Revisar la vista previa.
10. Seleccionar `Descargar PDF`.

## 6. Funciones del administrador

- Consultar mascotas de todos los propietarios.
- Buscar por mascota, propietario o correo.
- Filtrar por usuario.
- Cargar modelos base.
- Revisar modelos públicos y privados autorizados.

## 7. Recomendaciones de privacidad

- Publicar zona o barrio, no una dirección residencial exacta.
- Verificar el teléfono antes de descargar.
- No incluir documentos personales en fotografías.
- Utilizar fotografías sobre las que se tenga autorización.
- Revisar el cartel completo antes de compartirlo.
