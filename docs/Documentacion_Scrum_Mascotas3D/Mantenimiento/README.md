# Expediente de mantenimiento

## Propósito

Este expediente define cómo conservar el sistema operativo, seguro y comprensible después de la entrega. Incluye mantenimiento correctivo, adaptativo, perfectivo y preventivo.

## Contenido

| Documento | Finalidad |

| [Operación y respaldo](02_OPERACION_RESPALDO_Y_RECUPERACION.md) | Inicio, monitoreo, backups y restauración. |
| [Registro de cambios](03_REGISTRO_DE_CAMBIOS.md) | Historial técnico y formato de futuras versiones. |
| [Incidentes y continuidad](04_GESTION_DE_INCIDENTES.md) | Respuesta, severidad y contingencia. |

## Principio

Todo cambio de mantenimiento debe ingresar al Product Backlog o tratarse como incidente, incluir análisis de impacto, ejecutarse en un entorno controlado y finalizar con verificación y documentación.
