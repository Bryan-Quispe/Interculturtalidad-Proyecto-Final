# Checklist de entrega y evidencias

- [x] Visión y alcance.
- [x] Aplicación de Scrum.
- [x] Requisitos funcionales y no funcionales.
- [x] Product Backlog priorizado.

- [x] Definition of Ready y Definition of Done.

- [x] Plan de calidad y casos críticos.
- [x] Seguridad, privacidad y riesgos.

## Evidencia que debe capturarse antes de presentar

- [ ] Registro e inicio de sesión.
- [ ] Panel de usuario con mascotas propias.
- [ ] Panel administrador con filtro por propietario.
- [ ] Formulario de mascota con categoría.
- [ ] Google Maps y zona válida de Ecuador.
- [ ] Rechazo de ubicación extranjera.
- [ ] Selector 3D filtrado por especie.
- [ ] Textura original del modelo.
- [ ] Modos Rotar, Zoom y Pintar.
- [ ] Modelo personalizado después de guardar.
- [ ] Editor y vista previa del cartel.
- [ ] PDF abierto y nombre de archivo.
- [ ] Resultado de compilación frontend y backend.

## Protección antes de entregar

- [ ] Eliminar o rotar secretos expuestos.
- [ ] Confirmar que `.env` no se incluye en la entrega pública.
- [ ] Usar datos de prueba que no expongan personas reales sin permiso.
- [ ] Revisar que capturas no muestren tokens, claves o direcciones exactas.
- [ ] Probar la demostración desde una sesión limpia.
