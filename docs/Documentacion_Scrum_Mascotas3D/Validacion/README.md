# Expediente de validación

## Propósito

La validación determina si el producto satisface la necesidad de sus usuarios: registrar una mascota perdida, describirla de manera segura y producir material útil para buscarla.

## Diferencia clave

- **Validación:** “¿Construimos el producto correcto?” Se apoya en usuarios, escenarios y criterios de aceptación.
- **Verificación:** “¿Construimos correctamente el producto?” Se apoya en compilación, tipos, permisos y pruebas técnicas.

## Estado

Los escenarios y criterios están preparados y son coherentes con el incremento. La aprobación formal por usuarios externos requiere ejecutar el protocolo y adjuntar capturas, respuestas y firmas reales; no se presenta información simulada como evidencia.
