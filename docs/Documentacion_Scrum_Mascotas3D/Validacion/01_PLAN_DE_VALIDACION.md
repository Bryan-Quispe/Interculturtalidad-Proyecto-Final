# Plan de validación

## 1. Objetivo

Confirmar que propietarios y administradores comprenden el sistema, completan sus tareas principales y consideran útil el cartel generado.

## 2. Perfiles sugeridos

| Perfil | Cantidad mínima sugerida | Motivo |
| --- | ---: | --- |
| Propietario de mascota | 3 | Representa al usuario principal. |
| Persona que apoya búsquedas | 2 | Evalúa claridad pública del cartel. |
| Usuario con experiencia administrativa | 1 | Evalúa supervisión y filtros. |

Los participantes deben ser diferentes del desarrollador cuando sea posible.

## 3. Entorno

- Navegador moderno.
- Resolución móvil y escritorio.
- Datos de prueba sin información sensible.
- Backend y PostgreSQL disponibles.
- Google Maps configurado.
- Al menos un modelo por categoría y varias fotografías.

## 4. Procedimiento

1. Explicar el objetivo general sin enseñar cada control.
2. Entregar una tarea y observar sin intervenir.
3. Registrar finalización, errores, dudas y tiempo.
4. Solicitar opinión sobre claridad, confianza y utilidad.
5. Revisar el PDF producido.
6. Recoger consentimiento para usar capturas o respuestas.

## 5. Datos a registrar

| Métrica | Registro |
| --- | --- |
| Éxito de tarea | Completa, parcial o no completa. |
| Tiempo | Minutos y segundos. |
| Errores | Acción, consecuencia y recuperación. |
| Ayuda | Ninguna, ligera o directa. |
| Satisfacción | Escala definida en el instrumento elegido. |
| Comentario | Frase resumida sin datos sensibles. |

## 6. Umbrales propuestos

- Al menos 80 % de tareas críticas completadas sin ayuda directa.
- 100 % de participantes identifican teléfono y zona en el cartel.
- Ningún participante encuentra coordenadas exactas en el PDF.
- Al menos 80 % distingue Rotar, Zoom y Pintar.
- Ningún texto importante aparece ilegible o fuera del contenedor.

## 7. Ética y privacidad

- Solicitar consentimiento.
- No usar nombres inventados como participantes reales.
- Anonimizar respuestas si no existe autorización.
- Evitar direcciones, teléfonos o fotografías personales reales durante la prueba.
