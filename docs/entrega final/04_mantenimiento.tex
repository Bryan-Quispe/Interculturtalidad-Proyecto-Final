\section{Mantenimiento}

El mantenimiento contempla las acciones necesarias para conservar la plataforma estable, segura y preparada para futuras mejoras.

\subsection{Mantenimiento correctivo}
\begin{itemize}[leftmargin=*]
    \item Correcci\'on de errores de compilaci\'on y tipado.
    \item Ajustes en formularios para evitar datos incompletos.
    \item Actualizaci\'on del esquema Prisma cuando cambian los requisitos.
\end{itemize}

\subsection{Mantenimiento preventivo}
\begin{itemize}[leftmargin=*]
    \item Uso de cach\'e local para no repetir consultas innecesarias de ubicaci\'on.
    \item Separaci\'on por categor\'ia para evitar asignaci\'on err\'onea de modelos 3D.
    \item Revisi\'on de credenciales y variables de entorno.
\end{itemize}

\subsection{Mantenimiento evolutivo}
\begin{itemize}[leftmargin=*]
    \item Edici\'on avanzada de modelos 3D asignados.
    \item Integraci\'on futura con Google Maps para selecci\'on de zona/barrio.
    \item Mejora del flujo de b\'usqueda y comparaci\'on visual.
\end{itemize}

\subsection{Recomendaci\'on}
El sistema debe mantener su estructura modular para facilitar nuevas funcionalidades sin afectar la base operativa actual.
