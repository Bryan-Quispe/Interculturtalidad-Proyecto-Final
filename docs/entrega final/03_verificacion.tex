\section{Verificaci\'on}

La verificaci\'on asegura que la implementaci\'on cumple con lo dise\~nado y que la aplicaci\'on funciona de forma coherente en sus componentes principales.

\subsection{Elementos verificados}
\begin{itemize}[leftmargin=*]
    \item Compilaci\'on del frontend y backend sin errores de tipado.
    \item Generaci\'on correcta del cliente Prisma tras cambios de esquema.
    \item Carga de modelos 3D seg\'un categor\'ia.
    \item Visualizaci\'on de im\'agenes desde la carpeta de apoyo.
    \item Filtrado por zona o barrio en publicaciones p\'ublicas.
\end{itemize}

\subsection{Revisi\'on t\'ecnica}
\begin{itemize}[leftmargin=*]
    \item Las rutas API devuelven informaci\'on consistente.
    \item Las relaciones entre usuario, mascota y modelo 3D est\'an correctamente definidas.
    \item La interfaz mantiene coherencia visual en formularios y tarjetas.
\end{itemize}

\subsection{Pruebas de referencia}
Se tomaron como referencia las pantallas del home, login, registro y panel, adem\'as de la respuesta de los endpoints de mascotas y modelos 3D.
