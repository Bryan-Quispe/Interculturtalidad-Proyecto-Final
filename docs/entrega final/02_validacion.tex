\section{Validaci\'on}

La validaci\'on confirma que las funciones del sistema responden a la necesidad planteada: publicar mascotas, asociarlas a un due\~no y apoyarse en modelos 3D seg\'un la categor\'ia.

\subsection{Criterios validados}
\begin{itemize}[leftmargin=*]
    \item Cada mascota pertenece a un usuario registrado.
    \item Cada mascota se registra con categor\'ia: perro, gato o conejo.
    \item La ubicaci\'on se maneja como zona o barrio, no como direcci\'on exacta.
    \item Los modelos 3D se agrupan por categor\'ia para facilitar su selecci\'on.
    \item El usuario puede ver animales cercanos sin iniciar sesi\'on.
\end{itemize}

\subsection{Resultados esperados}
\begin{itemize}[leftmargin=*]
    \item B\'usqueda m\'as precisa de mascotas perdidas.
    \item Mejor experiencia al registrar y asociar informaci\'on visual.
    \item Reducci\'on del riesgo de exponer ubicaciones sensibles.
\end{itemize}

\subsection{Evidencia}
La validaci\'on se apoya en las pantallas principales del sistema, en los listados de mascotas por zona y en la asociaci\'on correcta entre animal y modelo 3D.
