# Entrega de documentos - Mascotas 3D / Wasi Wiwakuna 3D

**Proyecto:** Mascotas 3D - Wasi Wiwakuna 3D  
**Asignatura:** Desarrollo de Software Aplicada a la Interculturalidad  
**Metodología usada:** Scrum adaptado a proyecto académico  
**Periodo documentado:** domingo 24 de mayo de 2026 al sábado 25 de julio de 2026  
**Objetivo de la carpeta:** reunir la documentación necesaria para presentar el proceso, la solución y las evidencias solicitadas en la rúbrica de 7 puntos.

## Cómo usar esta carpeta

Esta carpeta está organizada para subir documentos y defender el proyecto sin tener que buscar en todo el repositorio. El orden recomendado es:

1. Leer la matriz de rúbrica.
2. Revisar el informe final del proyecto.
3. Presentar el proceso Scrum y el cronograma.
4. Usar backlog, bitácora, reviews, retrospectivas y pruebas como evidencia.
5. Cerrar con la guía de defensa y la lista de chequeo.
