# Anexos y referencias de evidencias

## 1. Propósito

Este documento indica qué anexos apoyan la entrega. Los anexos sirven para sostener afirmaciones durante la defensa y para que el docente pueda revisar el proceso sin buscar manualmente en todo el proyecto.

| Anexo | Uso |
| --- | --- |
| `rubrica_original.pdf` | PDF de evaluación usado como base para preparar la entrega. |
| `Presentacion.pdf` | Presentación de defensa. |
| `product_backlog.pdf` | Evidencia de Product Backlog. |
| `sprint_backlog.pdf` | Evidencia de Sprint Backlog. |
| `sprint_pllanning.pdf` | Evidencia de Sprint Planning. |
| `daily_scrum.pdf` | Evidencia de seguimiento tipo Daily Scrum. |

## 4. Cómo citar los anexos en exposición

- Para proceso Scrum: usar `02_PLAN_SCRUM_CRONOGRAMA.md`, `03_BACKLOG_Y_SPRINT_BACKLOGS.md` y PDFs Scrum.
- Para interculturalidad: usar `07_ENFOQUE_INTERCULTURAL_KICHWA.md` y `docs/TRADUCCION_KICHWA.md`.
- Para calidad: usar `06_CALIDAD_PRUEBAS_DEFENSA.md`, ERS, casos de uso y pruebas.
- Para cierre: usar `08_CHECKLIST_ENTREGA_Y_SUBIDA.md`.

## 5. Nota de honestidad académica

Los anexos no pretenden reemplazar una demostración del sistema. Sirven para demostrar el proceso usado y respaldar decisiones. Si un anexo se menciona en defensa, debe poder explicarse con palabras propias.
